## 2. Мобільна верстка (≥80% трафіку — критичний розділ)

Тестувати на ширинах 360 / 375 / 390 / 414 px.

### Меню та nav

- [ ] Бургер-меню відкривається при кліку на іконку
- [ ] Бургер-меню закривається при кліку на іконку або поза меню
- [ ] У відкритому меню видно всі лінки (Лікар, Всі операції, Контакти, Записатися)
- [ ] Лінки в меню клікабельні і ведуть на правильні URL
- [ ] Логотип у nav масштабується — не виходить за межі 390px
- [ ] Телефон у nav або клікабельний (`tel:` link), або захований у бургер
- [ ] Nav не перекриває верх контенту (sticky має padding-top на body)

### Hero на мобільному

- [ ] H1 не обрізається, не виходить за viewport
- [ ] H1 — 28-36px на мобільному (не 48px+ як на десктопі)
- [ ] Subtitle читабельний — не менше 14px
- [ ] CTA-кнопки не злипаються — gap мінімум 8px
- [ ] CTA-кнопки повної ширини або мінімум 44px height (touch target)
- [ ] Картка лікаря/показники у Hero — окремий блок під текстом, не справа

### Контент і секції

- [ ] Усі заголовки H2 не обрізаються
- [ ] Картки операцій / лікарів — 1 колонка на мобільному (не 2-3 як на десктопі)
- [ ] Експанд-блок (data-collapsed) розгортається без перекриття іншого контенту
- [ ] FAQ-аккордеон коректно відкривається і закривається
- [ ] Таблиці прайсу адаптовані — не виходять за viewport

### Sticky CTA / форми

- [ ] Sticky CTA bar (якщо є) не перекриває контент при скролі
- [ ] Sticky bar має margin-bottom або padding знизу щоб не закривати кінець сторінки
- [ ] Форма запису повністю заповнюється без зуму — поля 16px font-size мінімум (інакше iOS зумить)
- [ ] Чекбокс згоди має достатній touch target (мін 24×24px)
- [ ] Кнопка "Записатися" в формі — повна ширина або мінімум 44px height

### Footer

- [ ] Колонки футера стакаються вертикально на мобільному
- [ ] Телефони клікабельні (`tel:` links)
- [ ] Лінк на сайт-партнер lviv.oxford-med.com.ua відкривається у новій вкладці

### Тест чеклист

- [ ] Перевірено в Chrome DevTools на iPhone 12/13 (390px)
- [ ] Перевірено в реальному мобільному пристрої (опційно але бажано)
- [ ] Немає горизонтального скролу на жодній з ширин 360-414px
- [ ] Перевірено в landscape orientation на 812×375 (немає зламів)

## 7. Контент vs MD-файл

Порівняти кожен блок сторінки з відповідним файлом:

- `content/oxford-med/lviv/rappaporta.md` → /lviv/rappaporta
- `content/oxford-med/lviv/gisteroskopia.md` → /lviv/gisteroskopia
- `content/oxford-med/doctors/klimpush.md` → /lviv/doctors/klimpush

### Перевірка

- [ ] H1 — точно як у MD
- [ ] Title (meta) — як у MD
- [ ] Description (meta) — як у MD
- [ ] Метрики в Hero (тривалість, термін стаціонару) — відповідають MD
- [ ] Ціни — відповідають MD і `/lib/serviceMap.ts` (єдине джерело правди)
- [ ] Імена лікарів — точно як у MD (Климпуш Діана Львівна — не "Климпуш Д.Л." в headers)
- [ ] Спеціальність лікаря, роки досвіду, рейтинг — відповідають `/lib/surgeonsMap.ts`
- [ ] Адреса філії — відповідає `/lib/branchesMap.ts` (вул. Раппапорта, 2)
- [ ] Показання — повний список як у MD, без скорочень
- [ ] Протипоказання — повний список як у MD
- [ ] FAQ — всі питання і відповіді присутні
- [ ] Маршрут пацієнта — всі 5 кроків присутні

### Бренд-чистота і медичний тон

- [ ] **Слова "береться біопсія", "обов'язково береться зразок"** — НЕ зустрічаються в тексті (заміна на "за рішенням лікаря — береться зразок тканини")
- [ ] Жодних агресивних або тривожних формулювань ("страшний", "небезпечний", "терміново зверніться")
- [ ] Дисклеймер "Це орієнтир, а не остаточний обсяг" присутній під програмами/процедурами

### Placeholder-контроль

- [ ] **`[УТОЧНИТИ У КЛІНІКИ]` не видно на проді** при `NEXT_PUBLIC_SHOW_DRAFT_NOTES=false`
- [ ] `[PLACEHOLDER]` біля цін не видно на проді
- [ ] На preview-деплої (з `NEXT_PUBLIC_SHOW_DRAFT_NOTES=true`) ці алерти видно — для нашої внутрішньої роботи
