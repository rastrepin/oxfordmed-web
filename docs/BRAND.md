# Бренд Oxford Medical Львів

## Кольори
- Cyan `#1DB7ED` — основний CTA, посилання, акценти
- Cyan dark `#0E94C4` — hover для CTA
- Cyan light `#E8F7FD` — фон секцій, бейджі
- Cyan pale `#F4FBFE` — subtle backgrounds
- Green `#6BD333` — success, secondary акцент
- Green dark `#4FA821` — hover для green
- Green light `#EFFBE5` — success-фон
- Ink `#0E1F2E` — основний колір тексту і темного hero (footer)
- Gray-50 до Gray-900 — стандартна шкала

## Шрифти
- Source Serif 4 — H1 та великі заголовки (через Google Fonts)
- Fixel Display — H2 / H3
- Fixel Text — body, UI

НЕ використовувати: Onest, Cormorant Garamond, Inter

## Hero
- Світлий фон (білий, gray-50, або cyan-pale)
- Текст темний на світлому
- H1 без italic
- Темний hero ЗАБОРОНЕНИЙ (Oxford = світла палітра)
